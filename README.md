# flipbot-app

Mini App Telegram per gestire le ricerche di [flipbot](https://github.com/AndreaZocco/flipbot).

Pagina statica pubblicata con GitHub Pages: non contiene dati né segreti. Il bot le passa le ricerche nell'URL e riceve le modifiche tramite `Telegram.WebApp.sendData`.

La sorgente è `webapp/index.html` nel repository flipbot: questa è una copia pubblicata.
